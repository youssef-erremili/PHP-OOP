# PHP OOP Project

This project is a demonstration of **Object-Oriented Programming (OOP)** concepts in **PHP**. It showcases how to build a structured and maintainable PHP application using classes, objects, and key OOP principles such as **encapsulation**, **inheritance**, **abstraction**, and **polymorphism**.  

The project follows a simple **MVC (Model-View-Controller)** architecture:  
- **Models** handle data operations and database interaction.  
- **Controllers** manage the logic and connect the model with the view.  
- **Views** display data to the user.  

By applying OOP techniques, the codebase becomes cleaner, reusable, and easier to extend. This approach improves scalability, testing, and long-term maintainability for any PHP application.
